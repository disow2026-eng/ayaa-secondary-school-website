How to Use

👁 Live Preview
Click Preview in the topbar to open a split-view of the site. It updates automatically as you type.
↩ Undo / Redo
Use the ↩ ↪ buttons in the topbar, or Ctrl+Z / Ctrl+Y to step through your changes.
+ Adding Items
In Gallery, Impact, and Projects — use + Add buttons to add new items. Click Remove to delete one.
🖼 Images
Upload photos in Media tab. Then use Choose image on any section to pick them.
💾 Save + Go Live
Save stores your changes. Go Live publishes them to the website for everyone to see.
